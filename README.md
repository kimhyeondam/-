## 핵심 요약

**구조적 전제 3가지**

1. 시장의 크기 = 물류 반경. 운반비가 납품가의 15~30%이므로 반경 밖은 애초에 못 이긴다.
2. 승부는 견적 요청 전에 끝난다. 개입 시점은 설계 단계와 낙찰 직후.
3. KS 규격품은 제품으로 차별화가 안 된다. 실제 차별점은 납기·현장 대응·서류·혼적 배송.

**매출 = 커버 현장 수 × 수주율 × 현장당 품목 수 × 단가**

단가는 건드리지 않는다. 나머지 세 변수에 다섯 개 레버를 건다.

| 레버 | 임팩트 | 비용 |
|---|---|---|
| 착공 전 현장 레이더 | 최상 | 0원 / 주 4시간 |
| 대리점·자재상 커버리지 확장 | 최상 | 저비용 |
| 스펙인(설계 단계 침투) | 상 (6~18개월) | 인증비 |
| 현장당 품목 확대 | 상 | 0원 |
| 디지털 최소 세트 | 중 | 월 30~50만원 |

**실행**

- 사무·영업 인력이 있을 때: 하루 1과제 × 60일. `marketing/02-60일-실행표.html` 순서대로.
- 대표 혼자 다 할 때: `marketing/03-혼자하는-수주.html`의 첫 4주 12과제 → 이후 주간 시간표(주 약 2시간 20분)만 유지.

## 1인 운영일 때 달라지는 것

- 제약은 돈이 아니라 **시간**. 모든 방법을 "투입 시간당 매출"로 평가.
- 마케팅을 별도 업무로 만들지 않는다. **출고·세금계산서·입고·회계마감·견적** 다섯 접점에 1~3분짜리 동작을 붙인다.
- 발은 남의 발을 쓴다. **대리점·운송기사·원자재 공급사 영업**이 영업 조직.
- 캐파가 상한이므로 "더 많은 주문"이 아니라 "더 좋은 주문". 안 받을 주문 기준을 먼저 정한다.
- 매출 공식: 거래처 수(대리점에 위임) × **거래처당 주문 횟수** × **주문당 금액**
