# 메모장

이 저장소는 **개인 메모장**입니다. 생각나는 것, 통화 내용, 아이디어, 거래처 정보 등을
그때그때 저장해 두고, 필요할 때 검색해서 찾는 용도로 씁니다.

## 저장 방법

Claude에게 이렇게 말하면 됩니다.

- "이거 저장해줘: (내용)"
- "오늘 ○○ 거래처랑 통화한 내용 메모해줘: (내용)"

그러면 `메모/` 폴더에 `날짜-제목.md` 형식의 파일로 저장되고, `메모/목록.md`에도 한 줄 추가됩니다.

## 찾는 방법

1. **Claude에게 물어보기** : "메모에서 ○○ 찾아줘" 라고 하면 관련 메모를 찾아 읽어드립니다.
2. **GitHub에서 직접 검색** : 저장소 페이지 상단 검색창에 단어를 입력하면 메모 본문까지 검색됩니다.
   (예: `맨홀 단가` 처럼 단어 두 개를 넣으면 둘 다 들어있는 메모를 찾아줍니다)
3. **목록 훑어보기** : [`메모/목록.md`](메모/목록.md)를 열면 날짜·제목·태그가 한눈에 보입니다.

## 메모 한 장의 모양

```
# 제목
- 날짜: 2026-09-19
- 태그: #거래처 #견적
## 내용
(자유롭게)
```

태그는 나중에 검색할 때 걸리라고 붙이는 꼬리표입니다. 예: `#거래처` `#견적` `#현장` `#아이디어` `#할일`
