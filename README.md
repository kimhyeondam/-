# 현담토목 운영 OS

혼자 운영하면서 영업·마케팅·재고·응대를 전부 해야 하는 회사를 위한 작업 도구입니다.
서버도 구독료도 없습니다. CSV 몇 개와 파이썬 스크립트 하나, 그리고 Claude Code 입니다.

## 왜 이렇게 만들었나

혼자 하면 일이 안 되는 이유는 몰라서가 아니라 **기억이 새기 때문**입니다.
견적 보내고 잊고, 통화하고 안 적고, 재고 떨어진 걸 주문 받고 나서 압니다.
그래서 이 저장소는 딱 하나를 합니다 — **기억해야 할 것을 줄입니다.**

## 처음 한 번

Claude Code 에서 `/초기설정` 을 실행하십시오. 순서대로 물어봅니다.
직접 하시려면 `data/*.csv` 를 엑셀로 열어 채우면 됩니다. (UTF-8 CSV라 그냥 열립니다.)

| 채울 것 | 파일 |
|---|---|
| 회사 정보·견적 조건 | `설정/회사정보.md` |
| 품목·판매단가·원가(매입가)·조달가 | `data/품목.csv` |
| 대분류별 마진율 | `data/마진율.csv` |
| 야적장 실사 재고·안전재고 | `data/재고.csv` |
| 거래처 (거래/휴면/미거래) | `data/거래처.csv` |

다 되면 `python3 scripts/ops.py 예시삭제` 로 예시 행을 정리합니다.

## 매일 쓰는 법

Claude Code 에 **그냥 말하면 됩니다.** 명령어를 외울 필요 없습니다.

> "오늘 뭐 해야 돼?"
> "대창건자재에 흄관 600 12본 나갔어"
> "한길건설 ○○현장 흄관600 120본 맨홀 8조 견적 좀"
> "이 문의 왔는데 답장 좀 써줘: [붙여넣기]"
> "이번 주 어땠어?"

### 슬래시 커맨드

| 명령 | 하는 일 |
|---|---|
| `/아침` | 오늘 할 일을 3가지로 압축. 첫 마디까지 정해줍니다 |
| `/견적` | 말로 하면 계산하고 견적서 HTML 생성 + 발송 문구까지 |
| `/응대` | 받은 문의 붙여넣으면 답변 초안 + 기록 + 다음 약속 |
| `/현장조사` | 입찰·착공 정보를 찾아 레이더에 등록 |
| `/콘텐츠` | 블로그·카톡·플레이스용 홍보 글 |
| `/마감` | 주간 KPI, 누락 기록 점검, 다음 주 계획 |
| `/초기설정` | 처음 한 번, 실제 데이터로 갈아끼우기 |

### 직접 실행 (터미널)

```bash
python3 scripts/ops.py 브리핑          # 오늘 처리할 일 전부
python3 scripts/ops.py 재고            # 재고 현황과 경보
python3 scripts/ops.py 출고 --코드 HP600 --수량 12 --상대처 대창건자재
python3 scripts/ops.py 입고 --코드 HP600 --수량 40
python3 scripts/ops.py 조정 --코드 HP600 --수량 33      # 실사 결과로 덮어쓰기
python3 scripts/ops.py 품목 --찾기 648              # 품목 코드 검색 (수백 개라 필수)
python3 scripts/ops.py 견적 --거래처 한길종합건설 --품목 "CP503:120,JC001:8" --운반비 450000
python3 scripts/ops.py 판매가설정                   # 원가 + 마진율.csv 로 판매단가 생성
python3 scripts/ops.py 견적상태 --번호 20260901-01 --상태 수주
python3 scripts/ops.py 활동 --상대 "김부장" --내용 "재고 문의" --다음 "견적 발송" --다음일 2026-09-05
python3 scripts/ops.py 현장            # 현장 레이더 (--미접촉 으로 놓친 것만)
python3 scripts/ops.py 주간            # KPI 집계
python3 scripts/ops.py 재고공개        # 대리점 발송용 재고 문자
python3 scripts/ops.py 대시보드        # 대시보드.html 갱신
```

## 매일 아침 브리핑이 잡아내는 것

1. 기한이 온 후속조치 (며칠 지났는지까지)
2. 착공 임박한데 아직 접촉 못 한 현장 — **여기가 매출이 새는 곳입니다**
3. 재고 부족 + 생산 리드타임상 지금 걸어야 하는 품목
4. 보내놓고 회신 없는 견적
5. 90일 넘게 조용한 거래처

## 전략 문서

무엇을 왜 하는지는 아래 두 문서에 있습니다. 브라우저에서 바로 열립니다.

| 파일 | 내용 |
|---|---|
| `marketing/01-수주전략.html` | 진단, 매출 분해, 5개 레버, 90일 로드맵, KPI |
| `marketing/02-60일-실행표.html` | 하루 1과제 × 60일 체크리스트 |
| `marketing/03-혼자하는-수주.html` | **1인 운영 버전** — 회계·제품·출고·입고·영업을 한 사람이 할 때의 재분석. 매일 업무 속 5개 접점, 주 2시간 시간표, 첫 4주 12과제 |
| `cafe24/` | **카페24 쇼핑몰 상품 등록 자료** — `data/품목.csv`의 판매단가를 카페24 엑셀 일괄등록 파일로 변환. 생성 스크립트와 등록 순서 안내 포함 |

**매출 = 커버 현장 수 × 수주율 × 현장당 품목 수 × 단가**
단가는 건드리지 않고 나머지 세 변수를 올립니다. 이 도구는 그 세 가지를 매일 추적합니다.

## 마케팅 핵심 요약

**구조적 전제 3가지**

1. 시장의 크기 = 물류 반경. 운반비가 납품가의 15~30%이므로 반경 밖은 애초에 못 이긴다.
2. 승부는 견적 요청 전에 끝난다. 개입 시점은 설계 단계와 낙찰 직후.
3. KS 규격품은 제품으로 차별화가 안 된다. 실제 차별점은 납기·현장 대응·서류·혼적 배송.

| 레버 | 임팩트 | 비용 |
|---|---|---|
| 착공 전 현장 레이더 | 최상 | 0원 / 주 4시간 |
| 대리점·자재상 커버리지 확장 | 최상 | 저비용 |
| 스펙인(설계 단계 침투) | 상 (6~18개월) | 인증비 |
| 현장당 품목 확대 | 상 | 0원 |
| 디지털 최소 세트 | 중 | 월 30~50만원 |

**실행**

- 사무·영업 인력이 있을 때: 하루 1과제 × 60일. `marketing/02-60일-실행표.html` 순서대로.
- 대표 혼자 다 할 때: `marketing/03-혼자하는-수주.html`의 첫 4주 12과제 → 이후 주간 시간표(주 약 2시간 20분)만 유지.

## 1인 운영일 때 달라지는 것

- 제약은 돈이 아니라 **시간**. 모든 방법을 "투입 시간당 매출"로 평가.
- 마케팅을 별도 업무로 만들지 않는다. **출고·세금계산서·입고·회계마감·견적** 다섯 접점에 1~3분짜리 동작을 붙인다.
- 발은 남의 발을 쓴다. **대리점·운송기사·원자재 공급사 영업**이 영업 조직.
- 캐파가 상한이므로 "더 많은 주문"이 아니라 "더 좋은 주문". 안 받을 주문 기준을 먼저 정한다.
- 매출 공식: 거래처 수(대리점에 위임) × **거래처당 주문 횟수** × **주문당 금액**
