# 콘크리트 2차제품 마케팅

토목·구조용 콘크리트 2차제품(흄관·맨홀·측구·옹벽블록 등) 제조사의
매출 확대를 위한 전략 문서와 실행표입니다.

판매 경로: 건설사·시공사 직납 + 대리점·자재상 유통

## 문서

| 파일 | 내용 |
|---|---|
| `marketing/01-수주전략.html` | 진단, 매출 분해, 5개 레버, 90일 로드맵, KPI, 금지사항 |
| `marketing/02-60일-실행표.html` | 위 전략을 주 5일 × 12주, 하루 1과제로 쪼갠 체크리스트 + 추가 레버 10개 |
| `marketing/03-혼자하는-수주.html` | **1인 운영 버전** — 회계·제품·출고·입고·영업을 한 사람이 할 때의 재분석. 매일 업무 속 5개 접점, 남의 발 구조, 직접/자동화/외주/버림 분류, 주 2시간 시간표, 첫 4주 12과제 |

두 파일 모두 브라우저에서 바로 열립니다.

## 핵심 요약

**구조적 전제 3가지**

1. 시장의 크기 = 물류 반경. 운반비가 납품가의 15~30%이므로 반경 밖은 애초에 못 이긴다.
2. 승부는 견적 요청 전에 끝난다. 개입 시점은 설계 단계와 낙찰 직후.
3. KS 규격품은 제품으로 차별화가 안 된다. 실제 차별점은 납기·현장 대응·서류·혼적 배송.

**매출 = 커버 현장 수 × 수주율 × 현장당 품목 수 × 단가**

단가는 건드리지 않는다. 나머지 세 변수에 다섯 개 레버를 건다.

| 레버 | 임팩트 | 비용 |
|---|---|---|
| 착공 전 현장 레이더 | 최상 | 0원 / 주 4시간 |
| 대리점·자재상 커버리지 확장 | 최상 | 저비용 |
| 스펙인(설계 단계 침투) | 상 (6~18개월) | 인증비 |
| 현장당 품목 확대 | 상 | 0원 |
| 디지털 최소 세트 | 중 | 월 30~50만원 |

**실행**

- 사무·영업 인력이 있을 때: 하루 1과제 × 60일. `marketing/02-60일-실행표.html` 순서대로.
- 대표 혼자 다 할 때: `marketing/03-혼자하는-수주.html`의 첫 4주 12과제 → 이후 주간 시간표(주 약 2시간 20분)만 유지.

## 1인 운영일 때 달라지는 것

- 제약은 돈이 아니라 **시간**. 모든 방법을 "투입 시간당 매출"로 평가.
- 마케팅을 별도 업무로 만들지 않는다. **출고·세금계산서·입고·회계마감·견적** 다섯 접점에 1~3분짜리 동작을 붙인다.
- 발은 남의 발을 쓴다. **대리점·운송기사·원자재 공급사 영업**이 영업 조직.
- 캐파가 상한이므로 "더 많은 주문"이 아니라 "더 좋은 주문". 안 받을 주문 기준을 먼저 정한다.
- 매출 공식: 거래처 수(대리점에 위임) × **거래처당 주문 횟수** × **주문당 금액**

## 팔아유 시제품

`community/index.html` — 토목·건축자재 **단가비교·견적 플랫폼 팔아유**의 시제품(시연용 화면). 브라우저에서 바로 열립니다.

**중심 기능 (누구나 / 가입 회사)**

| 기능 | 내용 |
|---|---|
| 단가비교 | 분류(콘크리트 2차제품·레미콘·철근·골재·건축자재)와 검색으로 같은 규격의 판매사별 단가를 비교. 방문자도 볼 수 있음 |
| 현장 도착 금액 | 수량·현장 지역을 넣으면 자재비 + 운반비(대수 × 1대 운반비)로 합계 비교, 배송 지역 밖·최소 주문 미달 표시 |
| 견적 요청 | 특정 판매사 또는 배송 가능한 판매사 전체에 요청, 받은 견적을 합계 순으로 비교하고 선택 |
| 판매 등록 | 판매사가 단가·운반비·배송 지역·납기·KS 여부 등록, 단가 갱신일 표시(오래된 단가는 눈에 띄게) |

**게시판 (읽기는 누구나, 글·댓글은 가입 회사)**

| 게시판 | 용도 | 추가 입력칸 |
|---|---|---|
| 자유게시판 | 현장 이야기, 질문, 구인·구직 | — |
| 토목자재 뉴스 | 업계·발주·정책 소식, 자재 시세 기사 | 출처 링크 |
| 신제품 소식 | 새 제품·규격 홍보 (판매사 홍보는 이곳에만) | 제품명·규격·제조사·출시일, 단가표에 같은 제품이 있으면 "단가 비교하기" 버튼 |

- 검색, 댓글, 공지 고정(운영자), 신고 → 즉시 숨김 → 운영자가 복구/삭제
- 거래처 대금 이야기("대금을 안 줘요" 등)와 담합·욕설·개인정보는 글과 댓글에서 막고 결제조회 양식으로 안내

**부가 기능 (승인된 판매사 전용) — 거래처 결제조회**

- 받은 견적 요청마다 요청 회사의 결제조회 결과가 표시됨 (견적 주기 전에 확인)
- 운영규칙 초안 그대로: 증빙 확인 후 공개, 금지 표현 자동 차단, 법원 확인 도장, 로그인 없는 이의제기 → 즉시 비공개, 변제 시 삭제, 3년 만료, 처리 기록

**담합 예방**: 단가는 판매사가 구매자에게 공개한 판매가로만 다루고, "가격 맞추자" 같은 표현은 입력 단계에서 막습니다.

상단 "시연용 보기"에서 방문자 / 구매사 / 판매사 / 운영자 화면을 바꿔 볼 수 있습니다.
