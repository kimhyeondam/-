# 카페24 쇼핑몰 상품 등록 자료 (현담토목)

현담토목 단가표를 카페24 **상품 엑셀 일괄등록** 형식으로 정리한 자료입니다.
가격 출처는 구글드라이브의 `제일이앤씨 단가표.xlsx`(2025년 6월, 나라장터 식별번호 포함)이며,
`스마트스토어가격단가표.xlsx`(2025년 1월)와 `ㅈ조달가격` 시트로 교차 확인했습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `현담토목_카페24_상품등록.xlsx` | 카페24에 올릴 엑셀. 시트 5개 (아래 설명) |
| `products.py` | 제품·규격·가격 원본 데이터. **가격이 바뀌면 이 파일의 숫자만 고치면 됩니다** |
| `generate_cafe24_excel.py` | `products.py`를 읽어 엑셀을 다시 만드는 스크립트 (`python3 generate_cafe24_excel.py`) |

### 엑셀 시트 5개

| 시트 | 용도 |
|---|---|
| `카페24_규격별등록` | **권장.** 규격 하나를 상품 하나로 등록 (208개). 규격마다 가격이 크게 달라도 문제가 없고, 네이버 검색에도 규격별로 잡힙니다 |
| `카페24_옵션형등록` | 제품군 하나를 상품 하나로 등록하고 규격을 옵션(선택상자)으로 넣는 방식 (21개). 올린 뒤 옵션별 추가금액을 따로 입력해야 합니다 |
| `옵션추가금액표` | 옵션형으로 올렸을 때 규격별로 입력할 추가금액 |
| `제품마스터_단가표` | 사람이 보는 단가표. 견적서·전화 상담용 |
| `카페24_열설명` | 엑셀의 각 열에 무엇을 넣었는지, 코드값(T/F, A, C 등)이 무슨 뜻인지 |

## 등록한 제품 (21개 제품군, 208개 규격)

| 분류 | 제품 | 규격 수 | 가격 |
|---|---|---|---|
| 수로관 | 벤치플륨관 3종 | 17 | 50,000 ~ 402,000 |
| 수로관 | 측구수로관 일반형 / 앵글형 | 5 + 5 | 44,000 ~ 194,000 |
| 수로관 | 원형사각수로관 매립형(NS-02) / 돌출형(NS-03) | 9 + 9 | 47,000 ~ 305,000 |
| 수로관 | 원형사각수로관 2구형 / 집수정 | 5 + 5 | 200,000 ~ 550,000 |
| 기초대 | 콘크리트 기초대 직각형 / 정방형 | 12 + 7 | 80,000 ~ 290,000 |
| 그레이팅·뚜껑 | 스틸그레이팅 (벤치플륨용 / 측구용 / 원형사각용) | 8 + 26 + 17 | 7,500 ~ 97,000 |
| 그레이팅·뚜껑 | 집수정 그레이팅+앵글 세트 | 22 | 20,000 ~ 279,000 |
| 그레이팅·뚜껑 | 맨홀 주철뚜껑 / 무소음 트렌치 | 11 + 8 | 23,000 ~ 311,000 |
| 맨홀·집수정 | 콘크리트 맨홀블록 원형·사각, 콘크리트 집수정 | 4 + 3 + 29 | 견적문의 |
| 블록·경계석 | 보강토블럭, 식생축조블럭, 경계석·보도블럭 | 2 + 1 + 3 | 견적문의 |

"견적문의" 제품은 단가표에 금액이 없어 **판매가 0 + '견적문의' 문구 표시**로 넣었습니다.
가격이 정해지면 `products.py`에서 `quote_only=True`를 지우고 금액을 넣으면 됩니다.

## 카페24에 올리는 순서

1. **분류 만들기**: 관리자 > 상품 > 분류 관리에서 `수로관`, `콘크리트 기초대`, `맨홀·집수정`, `그레이팅·뚜껑`, `블록·경계석` 5개를 만듭니다.
   만들면 분류마다 번호가 생깁니다. (엑셀 `상품분류 번호` 열에 이 번호를 넣으면 자동으로 분류됩니다. 비워도 등록은 됩니다.)
2. **양식 내려받기**: 관리자 > 상품 > 상품 등록 > **엑셀 등록** > 상품 등록 탭 > 엑셀 양식 다운로드.
3. **값 옮겨 넣기**: 내려받은 양식을 열고, 이 파일의 `카페24_규격별등록` 시트 2행부터 끝까지 복사해 양식의 2행에 붙여 넣습니다.
   - 열 이름이 똑같은지 1행끼리 한 번 비교해 주세요. 카페24가 양식을 바꿔 열이 하나라도 다르면, `카페24_열설명` 시트를 보고 같은 이름의 열로 옮기면 됩니다.
   - 양식에 없는 열을 더하거나, 있는 열을 지우면 업로드가 실패합니다.
4. **업로드**: 같은 화면에서 파일을 올립니다. 한 번에 1,000개까지 가능하므로 208개는 한 번에 됩니다.
5. **결과 확인**: 업로드 결과 화면에서 실패한 줄이 있으면 사유가 나옵니다. 대부분 열 이름 불일치나 빈 필수값입니다.
6. **배송 설정**: 관리자 > 설정 > 배송 설정에서 기본 배송을 **화물배송 / 착불**로 두면 모든 상품에 적용됩니다.
   (엑셀에서 `배송정보=F`, 즉 "기본 배송설정을 따름"으로 넣었습니다.)
7. **사진 넣기**: 상품 사진은 엑셀에 넣지 않았습니다. 두 가지 방법이 있습니다.
   - 상품이 몇 개 안 되면: 상품 관리 > 상품 수정 화면에서 직접 올리기
   - 한꺼번에 하려면: 관리자 > 디자인 > 웹FTP에 사진을 올린 뒤, 엑셀 `이미지등록(상세)` 등에 파일 이름만 적어 **상품 수정 엑셀**로 다시 올리기

## 자주 하는 질문

- **부가세는 포함인가요?** 원본 단가표(나라장터 기준)의 금액을 그대로 판매가로 넣었고, 과세상품(A)으로 설정했습니다. 공급가 기준으로 팔고 싶으면 `products.py`의 금액을 바꾸거나 관리자에서 일괄 할인/할증하세요.
- **운반비는요?** 착불이며 상세설명과 배송안내에 "운반비 별도(착불), 하차 장비 확인" 문구를 넣었습니다.
- **주문할 때 현장 주소를 받을 수 있나요?** 모든 상품에 `추가입력옵션`으로 "납품 현장 주소·하차장비 유무" 입력칸을 켜 두었습니다.
- **가격을 바꾸려면?** `products.py` 숫자 수정 → `python3 generate_cafe24_excel.py` 실행 → 관리자에서 **상품 수정 엑셀**(자체 상품코드 기준)로 업로드.

## 카페24 열 코드값 요약

| 열 | 값 | 뜻 |
|---|---|---|
| 진열상태·판매상태 | T / F | 함 / 안 함 |
| 과세구분 | A / B / C | 과세 / 면세 / 영세 |
| 주문수량 제한 기준 | O / P | 주문 기준 / 품목 기준 |
| 적립금 구분 | W / P | 원 / 퍼센트 |
| 옵션구성방식 | C / S / E / F | 조합 일체선택형 / 조합 분리선택형 / 상품 연동형 / 독립 선택형 |
| 옵션 입력 | `규격{값1|값2}` | 옵션이 여럿이면 `//`로 구분 |
| 배송정보 | F / T | 기본 배송설정 사용 / 개별 설정 |
| 국내/해외배송 | A / C | 국내 / 해외 |
