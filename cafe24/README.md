# 카페24 쇼핑몰 상품 등록 자료 (현담토목)

`data/품목.csv`(운영 OS의 품목·단가표, 538개)를 카페24 **상품 엑셀 일괄등록** 형식으로 변환한 자료입니다.
가격 원본은 `data/품목.csv` 하나뿐입니다. 판매단가는 `원가 × (1 + 마진율)`로 만들어지며(`data/마진율.csv`), **부가세 별도**입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `현담토목_카페24_상품등록.xlsx` | 카페24에 올릴 엑셀. 시트 5개 (아래 설명) |
| `generate_cafe24_excel.py` | `data/품목.csv`를 읽어 엑셀을 만드는 스크립트. 저장소 루트에서 `python3 cafe24/generate_cafe24_excel.py` |

### 가격이 바뀌었을 때

1. `data/품목.csv`를 고치거나 `python3 scripts/ops.py 판매가설정 --덮어쓰기`로 마진을 다시 적용
2. `python3 cafe24/generate_cafe24_excel.py` 실행
3. 카페24 관리자 > 상품 > 엑셀 등록 > **상품 수정** 탭에 올리기 (자체 상품코드 = 품목코드로 찾아 갱신)

### 부가세

카페24 `판매가`는 소비자가 보는 가격이므로 **판매단가 × 1.1(부가세 포함, 10원 단위 반올림)**으로 넣었고,
`공급가` 열에는 견적서와 같은 **부가세 별도 단가**를 그대로 두었습니다.
부가세 별도 금액을 그대로 판매가로 쓰고 싶으면 스크립트 위쪽의 `VAT_INCLUDED = True`를 `False`로 바꾸고 다시 실행하세요.

### 엑셀 시트 5개

| 시트 | 용도 |
|---|---|
| `카페24_규격별등록` | **권장.** 품목 하나를 상품 하나로 등록 (538개). 규격마다 가격이 크게 달라도 문제가 없고, 네이버 검색에도 규격별로 잡힙니다 |
| `카페24_옵션형등록` | 제품군 하나를 상품 하나로 등록하고 규격을 옵션(선택상자)으로 넣는 방식. 올린 뒤 옵션별 추가금액을 따로 입력해야 합니다 |
| `옵션추가금액표` | 옵션형으로 올렸을 때 규격별로 입력할 추가금액 |
| `제품마스터_단가표` | 사람이 보는 단가표. 부가세 별도/포함 단가, 나라장터 식별번호, 중량 |
| `카페24_열설명` | 엑셀의 각 열에 무엇을 넣었는지, 코드값(T/F, A, C 등)이 무슨 뜻인지 |

## 등록 대상 (data/품목.csv 기준)

## 카페24에 올리는 순서

1. **분류 만들기**: 관리자 > 상품 > 분류 관리에서 `콘크리트 수로관`, `콘크리트 맨홀·집수정`, `주철 맨홀뚜껑·인상링·트렌치`, `PE관·부속`, `루프드레인` 5개를 만듭니다.
   만들면 분류마다 번호가 생깁니다. (엑셀 `상품분류 번호` 열에 이 번호를 넣으면 자동으로 분류됩니다. 비워도 등록은 됩니다.)
2. **양식 내려받기**: 관리자 > 상품 > 상품 등록 > **엑셀 등록** > 상품 등록 탭 > 엑셀 양식 다운로드.
3. **값 옮겨 넣기**: 내려받은 양식을 열고, 이 파일의 `카페24_규격별등록` 시트 2행부터 끝까지 복사해 양식의 2행에 붙여 넣습니다.
   - 열 이름이 똑같은지 1행끼리 한 번 비교해 주세요. 카페24가 양식을 바꿔 열이 하나라도 다르면, `카페24_열설명` 시트를 보고 같은 이름의 열로 옮기면 됩니다.
   - 양식에 없는 열을 더하거나, 있는 열을 지우면 업로드가 실패합니다.
4. **업로드**: 같은 화면에서 파일을 올립니다. 한 번에 1,000개까지 가능하므로 538개는 한 번에 됩니다.
5. **결과 확인**: 업로드 결과 화면에서 실패한 줄이 있으면 사유가 나옵니다. 대부분 열 이름 불일치나 빈 필수값입니다.
6. **배송 설정**: 관리자 > 설정 > 배송 설정에서 기본 배송을 **화물배송 / 착불**로 두면 모든 상품에 적용됩니다.
   (엑셀에서 `배송정보=F`, 즉 "기본 배송설정을 따름"으로 넣었습니다.)
7. **사진 넣기**: 상품 사진은 엑셀에 넣지 않았습니다.
   - 상품이 몇 개 안 되면: 상품 관리 > 상품 수정 화면에서 직접 올리기
   - 한꺼번에 하려면: 관리자 > 디자인 > 웹FTP에 사진을 올린 뒤, 엑셀 `이미지등록(상세)` 등에 파일 이름만 적어 **상품 수정 엑셀**로 다시 올리기

## 자주 하는 질문

- **운반비는요?** 착불이며 상세설명과 배송안내에 "운반비 별도(착불), 하차는 현장 부담" 문구를 넣었습니다. 운반비는 사장이 직접 계산한다는 운영 원칙 그대로입니다.
- **주문할 때 현장 주소를 받을 수 있나요?** 모든 상품에 `추가입력옵션`으로 "납품 현장 주소·하차장비 유무" 입력칸을 켜 두었습니다.
- **상품명이 너무 긴데요?** `품목명 + 규격`으로 자동 생성했습니다. 마음에 안 드는 이름은 엑셀에서 고쳐도 되고, `data/품목.csv`의 품목명을 고치면 다음 생성부터 반영됩니다.

## 카페24 열 코드값 요약

| 열 | 값 | 뜻 |
|---|---|---|
| 진열상태·판매상태 | T / F | 함 / 안 함 |
| 과세구분 | A / B / C | 과세 / 면세 / 영세 |
| 주문수량 제한 기준 | O / P | 주문 기준 / 품목 기준 |
| 적립금 구분 | W / P | 원 / 퍼센트 |
| 옵션구성방식 | C / S / E / F | 조합 일체선택형 / 조합 분리선택형 / 상품 연동형 / 독립 선택형 |
| 옵션 입력 | `규격{값1|값2}` | 옵션이 여럿이면 `//`로 구분 |
| 배송정보 | F / T | 기본 배송설정 사용 / 개별 설정 |
| 국내/해외배송 | A / C | 국내 / 해외 |
